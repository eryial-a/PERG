# PERG
This is the repository containing PERG's build files and latest build.

## What is PERG?
PERG is a simple rougelike poker game inspired by other games like Balatro, Wildfrost, and Solitarica.

## Install Instructions
To install, follow these steps:



### Download the PERG.7z file and extract it to a location of your choosing.
### Unzip the file
### Run PERG.exe

Alternatively, you may also import these files into a Unity 6000.3.6f1 editor and create a build from the source files.
